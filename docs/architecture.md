# Архитектура

## Общая схема (целевая)

```
                       ┌──────────────── корпус магнитолы Toyota ────────────────┐
                       │                                                         │
 кнопки, энкодеры ────►│  ESP32-S3 ─CC1101─433 МГц (как AC-44F6)─► ATOTO P8        │
 (родная панель)       │     │                                   │ AUX          │
                       │     ├─ I2C ─► VEML7700 (внешний свет)   ▼              │
                       │     ├─ ШИМ ─► LED у датчика P8   [аудиопроцессор?]      │
                       │     ├─ I2C ─► аудиопроцессор ─────────► усилитель ─► динамики
                       │     └─ serial ─► LCD Toyota (позже)                     │
                       └─────────────────────────────────────────────────────────┘
```

Канал ESP32 → P8 через повтор радиопакетов пульта — гипотеза (этап 1.6). Управление яркостью светом на датчике — проверено (0.3).

Громкость — открытый вопрос (этап 3.1):
- **через P8** (команды пульта) — проще, меньше железа;
- **через аудиопроцессор** в тракте — мгновенный отклик, не зависит от BLE, плюс тембр/фейдер.

## Модули прошивки

| Модуль | Ответственность |
|---|---|
| `input` | Матрица кнопок, энкодеры, дребезг, короткое/долгое нажатие, комбинации |
| `remote` | Радиоканал пульта 433 МГц через CC1101 (SPI): отправка кодов команд. Позже, если P8 примет, — BLE HID |
| `brightness` | VEML7700 → сглаживание → кривая → ШИМ |
| `learn` | Режим обучения: точка «люксы → желаемая яркость» по кнопкам |
| `settings` | Хранение в NVS |
| `web` | Точка доступа, страница калибровки |
| `ota` | Обновление по Wi-Fi (ArduinoOTA + загрузка `.bin` через веб), откат, безопасный режим |
| `display` | Обратная связь о режиме: LCD Toyota (позже) / виртуальный дисплей в Serial и вебе, мигание светодиода, пищалка |

## Раскладка управления (черновик)

| Контрол | Обычный режим | Долгое нажатие / комбо |
|---|---|---|
| PWR·VOL крутить | Громкость | — |
| PWR·VOL нажать | Mute / Play-Pause | — |
| CONTROL крутить | Поправка яркости ± | В меню — изменить параметр |
| CONTROL нажать | Перебор параметров | — |
| TUNE/TRACK ∧∨ | След./пред. трек | — |
| 1–6 | Голосовой ассистент, звонок и т.д. | — |
| 3 DISP | — | 3 с: режим обучения яркости |
| TV, AM/FM, MD, CD, LOAD, AUTO·P, eject | Резерв | — |

Без LCD пользователь не видит, в каком режиме панель, поэтому каждое переключение режима сопровождается сигналом (пищалка/мигание) и отображается в виртуальном дисплее.

Набор команд для P8 зависит от того, что поддерживает пульт AC-44F6 / P8 (этапы 1.6, 1.7). Кнопки без команды в P8 — под функции ESP32.

## Распиновка nRF24L01+ (черновик, этап 1.6)

Устарело: пульт на 433 МГц (этап 0.5). CC1101 тоже на SPI — распиновку переделать под него.

| nRF24 | ESP32-S3 | Примечание |
|---|---|---|
| VCC | 3V3 | **Не 5V.** Рядом с модулем 100 мкФ («+» к VCC) + 100 нФ |
| GND | GND | |
| CE | GPIO 9 | |
| CSN | GPIO 10 | |
| MOSI | GPIO 11 | |
| SCK | GPIO 12 | |
| MISO | GPIO 13 | |
| IRQ | GPIO 14 | необязательно |

- GPIO 10–13 — аппаратный SPI2 (FSPI). Обходим: 0, 3, 45, 46 (влияют на загрузку), 35–37 (PSRAM на N16R8/N8R8), 19/20 (USB).
- В прошивке выводы задаются явно: `SPI.begin(12, 13, 11, 10)` — на S3 выводы по умолчанию часто не работают.
- Схема нарисована для Espressif DevKitC-1 (`docs/wiring-nrf24.html`, [артефакт](https://claude.ai/artifact/EMp7Bdj7qBsdGy3my7x6jk)). Заказанная плата — Waveshare ESP32-S3-DEV-KIT, у неё другой порядок выводов, номера GPIO те же. У mini-модуля контакты в один ряд — распиновку сверить по плате. Перерисовать, когда придут.

## Питание

**Стол:** USB-C от MacBook/зарядки → ESP32 → 3V3 платы питает nRF24, VEML7700, кнопки. Не подавать одновременно USB и внешние 5 В на вывод 5V. Повербанк — только с режимом малого тока (иначе отключится).

**Машина, временно (1.11):** USB-зарядка в прикуриватель → кабель → ESP32.

**Машина, постоянно (3.3):**
```
ACC 12 В ─► предохранитель 1 А ─► защита от переполюсовки ─► TVS ─► DC-DC 12→5 В ─► 5V ESP32
                                                                                   └─ 3V3 платы ─► nRF24, датчики
```
Земля общая (ESP32, DC-DC, кузов). P8 питается отдельно. Пропадание ACC — штатная ситуация: не писать в NVS в момент выключения.
