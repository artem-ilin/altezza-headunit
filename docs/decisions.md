# Журнал решений

Формат: дата — решение — почему — какие были альтернативы.

---

### 2026-11-03 — Магнитола Toyota как панель управления, а не как источник звука
**Почему:** штатный вид, физические кнопки и крутилки. CD/MD-механизмы и родная электроника не нужны, P8 и так используется 100% времени.
**Альтернативы:** своя панель с нуля (как в видео Garage Tinkering) — больше работы с механикой и внешним видом.

### 2026-11-03 — Микроконтроллер ESP32-S3
**Почему:** BLE 5 (имитация пульта), Wi-Fi (веб-настройка, OTA), много GPIO, встроенный USB.
**Альтернативы:** ESP32-C3 (мало ног), RP2040 (нет BLE/Wi-Fi без доп. модуля).

### 2026-11-03 — Прошивка: PlatformIO + Arduino (C++)
**Почему:** большая экосистема (NimBLE, VEML7700, веб-сервер, OTA), быстрый старт. При необходимости можно точечно спуститься в ESP-IDF.
**Альтернативы:** ESP-IDF (больше кода), MicroPython (неудобен для BLE HID), Rust esp-rs (BLE HID менее зрелый).

### 2026-11-03 — Яркость P8 через «подсветку» его датчика светодиодом
**Почему:** датчик P8 закрыт корпусом навигации, оптическая трубка пропускает слишком мало света. Корпус изолирует датчик от внешнего света, поэтому светодиод даёт полный контроль. Официального способа управлять яркостью извне не найдено.
**Детали:** внешний датчик VEML7700 → кривая → ШИМ (высокая частота + RC-фильтр). Белый/зелёный светодиод, не ИК. Светоизоляция от подсветки экрана (иначе обратная связь).

### 2026-11-03 — Управление P8 через имитацию пульта AC-44F6 (BLE)
**Почему:** проводного входа для кнопок руля у P8 нет. Родной пульт беспроводной.
**Запасной план:** ESP32 «нажимает» кнопки разобранного родного пульта через оптопары/транзисторы.
**Статус:** гипотеза, проверяется на этапе 0.1 / 1.5.

### 2026-11-03 — Ночной режим Android Auto не трогаем
**Почему:** решение «день/ночь» принимает прошивка P8 внутри протокола AA. Извне не подменить без взлома прошивки. Наблюдения показывают, что P8 не переключает ночной режим по датчику.
**Что остаётся:** режим P8 по времени (проверить) или ручной выбор темы в Maps/Waze.

### 2026-11-03 — Порядок работы: телефон → ESP32 на столе → магнитола
**Почему:** магнитолу из Японии ждать месяцами. Всю логику прошивки можно проверить на макетке с энкодерами и кнопками.

### 2026-11-03 — Всё в git-репозитории, без Claude Project
**Почему:** единый источник правды для кода, документации и результатов реверса. Claude Code работает с репозиторием напрямую, контекст — в `CLAUDE.md`.
