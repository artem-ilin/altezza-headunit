# Roadmap

Логика: магнитола из Японии будет ехать месяцами, поэтому сначала проверяем все гипотезы дешёво и без неё. Каждый этап отвечает на конкретный вопрос, и следующий этап имеет смысл, только если ответ «да» (или найден обходной путь).

Статусы: ⬜ не начато · 🟨 в работе · ✅ проверено · ❌ не сработало · ➖ отменено

## Этап 0 — телефон и копеечные тесты (≈ €0–3)

Вопрос: **можно ли вообще управлять P8 извне и его яркостью?**

| # | Задача | Как | Статус |
|---|---|---|---|
| 0.1 | Разведка пульта AC-44F6 | Не виден ни в nRF Connect, ни в Bluetooth телефона, нет в списке P8; не Bluetooth; приёмник внутри P8. ~~2.4 ГГц~~ — по FCC (0.5) пульт на 433 МГц. Подробно — `atoto-p8.md` | ✅ |
| 0.2 | Принимает ли P8 обычную BT-клавиатуру | Второго Android нет → перенесено на ESP32 (1.7) | ➖ |
| 0.3 | Управляется ли автояркость светом на датчике | Проверено фонариком: промежуточный свет → промежуточная яркость, реакция 1–2 с. Кривая и пороги — на калибровке 1.4 | ✅ |
| 0.4 | Как P8 включает ночной режим | Сам не переключается, в меню P8 пункта нет, от датчика не зависит (проверено). В AA на телефоне Day/night mode for maps = Automatic, но не переключается (проверено). Осталось: посмотреть остальные варианты в этом списке | 🟨 |
| 0.5 | FCC ID пульта и P8 | P8 — [2AYLO-P5P8P9P10](https://fccid.io/2AYLO-P5P8P9P10); заявки на пульт нет. На внутренних фото P8 — приёмник **«433MHz-RX»**; кварц пульта 13.56 МГц × 32 = 433.92 МГц; инструкция P8: «Built-in 433MHZ AC-44F6 Remote receiver» → пульт на **433 МГц** (проверено), nRF24 не подходит. На коробке FCC ID 2AQ49-A6F7S8P8 — вероятно, общая наклейка линейки (в гранте нет 5 ГГц). Модуляция и скорость в документах не указаны — определить на 1.6. Подробно и ссылки на документы FCC — `atoto-p8.md` | ✅ |

0.6 (необязательно, низкий приоритет): единственный USB-C P8 занят адаптером камер. Если USB-C хаб уже есть под рукой — проверить, работают ли через него камеры, и реагирует ли P8 на медиа-клавиши USB-клавиатуры. Специально хаб не покупать; камеры важнее.

0.7 (подготовка к 1.6, без плат на руках):
1. Поискать готовые коды AC-44F6: протоколы rtl_433 и issues, форумы, коллекции `.sub`-файлов Flipper Zero на GitHub.
2. Инструкция P8 ([FCC](https://fccid.io/2AYLO-P5P8P9P10/User-Manual/User-manual-6907050)) и меню P8: есть ли сопряжение пульта (Pairing / Learn), полный список кнопок. Если P8 «обучается» на пульт — вероятно фиксированный ID без плавающего кода.
3. Распиновка EBYTE E07-M1101D-SMA по даташиту, схема подключения к Waveshare ESP32-S3 вместо nRF24.
4. Заготовка прошивки-сниффера: CC1101 на 433.92 МГц, прерывание на GDO0, длительности импульсов в Serial (RadioLib или SmartRC-CC1101 + RCSwitch). Собрать `pio run`, чтобы прошить в день доставки.

Своё APK пишем, только если готовых инструментов (nRF Connect, эмулятор BT-клавиатуры) не хватит (например, если нужно точно повторить Report Map пульта со смартфона). Скорее всего, быстрее и дешевле сразу перейти к ESP32.

0.3: корпус уже изолирует датчик от света экрана (проверено) — при монтаже светодиода эту изоляцию не нарушить.

**Параллельно сразу заказать железо для этапа 1** (см. `shopping.md`) — доставка 2–3 недели.

## Этап 1 — ESP32 вне машины / от powerbank (≈ €25–40)

Вопрос: **работает ли вся логика прошивки до появления магнитолы?**

| # | Задача | Зависит от | Статус |
|---|---|---|---|
| 1.1 | Скелет прошивки, сборка, прошивка платы. Скелет есть; локальная сборка и прошивка платы — не проверены | — | 🟨 |
| 1.2 | **OTA по Wi-Fi** (сразу после скелета, чтобы дальше всё обновлять без разборки): ArduinoOTA из PlatformIO + загрузка `.bin` через веб-страницу; откат на старую прошивку, безопасный режим по кнопке при старте; Wi-Fi включается по запросу | 1.1 | ⬜ |
| 1.3 | **Яркость:** VEML7700 → сглаживание → кривая → ШИМ светодиода у датчика P8 | 0.3 | ⬜ |
| 1.4 | Калибровка: прогон ШИМ 0→100%, отметка порогов P8, гистерезис | 1.3 | ⬜ |
| 1.5 | Точка доступа + веб-страница: кривая яркости, поправка, сброс | 1.3 | ⬜ |
| 1.6 | **Радиоканал пульта, 433 МГц** (по 0.5). 2× CC1101 (EBYTE E07-M1101D-SMA) заказаны 2026-11-05, доставка ~11.11; nRF24L01+ для пульта не годятся. ESP32 + CC1101: уточнить частоту (~433.92 МГц) и модуляцию (OOK/FSK), записать коды кнопок, повторить → P8 реагирует. Проверить, нет ли плавающего кода. Второй CC1101 — проверка своей передачи без P8 | 0.1, 0.5 | ⬜ |
| 1.7 | **BT-клавиатура (бывший 0.2):** принимает ли P8 ESP32 как BLE HID. Если да — перебор Consumer-кодов: что P8 понимает кроме громкости/треков (яркость? день/ночь? Home? навигация?) | 1.1 | ⬜ |
| 1.8 | **Имитация панели Toyota на макетке:** 2 энкодера с кнопкой + несколько кнопок. Слой input: дребезг, долгое нажатие, комбо | — | ⬜ |
| 1.9 | Раскладка управления (см. `architecture.md`) на макетных кнопках, режим обучения яркости (DISP + CONTROL) | 1.3, 1.6, 1.8 | ⬜ |
| 1.10 | Обратная связь без LCD: «виртуальный LCD» в Serial/вебе, мигание светодиода, звуковой сигнал (пищалка). Без этого непонятно, в каком режиме меню панель | 1.9 | ⬜ |
| 1.11 | Временная установка в машину: ESP32 от USB/powerbank, только яркость + пульт с макетной панели. USB-кабель вывести в доступное место (запасной путь прошивки) | 1.2, 1.3, 1.6 | ⬜ |
| 1.12 | **Запасной вариант для ночного режима** (если в 1.7 кода день/ночь не нашлось): проверить обновления прошивки P8 и спросить поддержку ATOTO, есть ли у P8 способ передавать «ночь» в Android Auto (скрытая настройка, вход подсветки и т. п.) | 1.7 | ⬜ |

Результат этапа: прошивка, которая полностью работает с макетной панелью. На этом этапе уже решается реальная проблема с яркостью.

| # | Задача | Статус |

## Этап 3 — звук, питание, установка

| # | Задача | Статус |
|---|---|---|
| 3.1 | Решение по громкости: только через P8 (BLE) или аудиопроцессор (TDA7419/PT2313) в тракте | ⬜ |
| 3.2 | Усилитель 4 канала (TDA7850 / TDA7388) | ⬜ |
| 3.3 | Питание: DC-DC 12→5 В, переполюсовка, TVS, ACC | ⬜ |
| 3.4 | Рамка/накладка консоли под штатную магнитолу, разъём Toyota | ⬜ |
| 3.5 | Шумы, земляная петля на AUX | ⬜ |
| 3.6 | **ILL/TAIL → ночь.** Провод габаритов в разъёме магнитолы: фары включены → ночной режим AA (механизм переключения — 0.4/1.7/1.12) и ночная кривая яркости. Делитель + оптрон на GPIO. Провод есть в любой штатной проводке (**гипотеза**: найти в текущем жгуте к Nakamichi — можно проверить до магнитолы, на 1.11) | ⬜ |
| 3.7 | **SPD → громкость по скорости.** Импульсы датчика скорости → частота → поправка громкости через P8. Есть ли SPD в разъёме магнитолы или только в жгуте навигации — **гипотеза**, проверить по распиновке | ⬜ |
| 3.8 | **REV → приглушение звука** на заднем ходу (камера P8 включается сама). Найти провод заднего хода (фонарь заднего хода, если в разъёме нет) | ⬜ |

## Идеи / бэклог

Необязательное, обсудить позже. В план этапов пока не входит.

| # | Идея | Статус |
|---|---|---|
| B.1 | **Открывание/закрывание шлагбаума с панели.** Железо то же — CC1101 433 МГц (из 1.6), отдельный модуль не нужен.
