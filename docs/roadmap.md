# Roadmap

Логика: магнитола из Японии будет ехать месяцами, поэтому сначала проверяем все гипотезы дешёво и без неё. Каждый этап отвечает на конкретный вопрос, и следующий этап имеет смысл, только если ответ «да» (или найден обходной путь).

Статусы: ⬜ не начато · 🟨 в работе · ✅ проверено · ❌ не сработало · ➖ отменено

---

## Этап 0 — телефон и копеечные тесты (≈ €0–3)

Вопрос: **можно ли вообще управлять P8 извне и его яркостью?**

| # | Задача | Как | Статус |
|---|---|---|---|
| 0.1 | Разведка пульта AC-44F6 | Не виден ни в nRF Connect, ни в Bluetooth телефона, нет в списке P8; по плате — свой протокол 2.4 ГГц, не Bluetooth (вывод). Подробно — `atoto-p8.md` | ✅ |
| 0.2 | Принимает ли P8 обычную BT-клавиатуру | Второго Android нет → перенесено на ESP32 (1.7) | ➖ |
| 0.3 | Управляется ли автояркость светом на датчике | Проверено фонариком: промежуточный свет → промежуточная яркость, реакция 1–2 с. Кривая и пороги — на калибровке 1.4 | ✅ |
| 0.4 | Как P8 включает ночной режим | Сам не переключается, в меню P8 пункта нет, от датчика не зависит (проверено). В AA на телефоне Day/night mode for maps = Automatic, но не переключается (проверено). Осталось: посмотреть остальные варианты в этом списке | 🟨 |
| 0.5 | FCC ID пульта и P8 | Найти на корпусе/под крышкой батарейки → отчёт на fccid.io: частоты, модуляция, скорость, фото платы. Покажет, поймает ли nRF24 | ⬜ |

Своё APK пишем, только если готовых инструментов (nRF Connect, эмулятор BT-клавиатуры) не хватит (например, если нужно точно повторить Report Map пульта со смартфона). Скорее всего, быстрее и дешевле сразу перейти к ESP32.

0.3: корпус уже изолирует датчик от света экрана (проверено) — при монтаже светодиода эту изоляцию не нарушить.

**Параллельно сразу заказать железо для этапа 1** (см. `shopping.md`) — доставка 2–3 недели.

## Этап 1 — ESP32 вне машины / от powerbank (≈ €25–40)

Вопрос: **работает ли вся логика прошивки до появления магнитолы?**

| # | Задача | Зависит от | Статус |
|---|---|---|---|
| 1.1 | Скелет прошивки, сборка, прошивка платы. Скелет есть; локальная сборка и прошивка платы — не проверены | — | 🟨 |
| 1.2 | **OTA по Wi-Fi** (сразу после скелета, чтобы дальше всё обновлять без разборки): ArduinoOTA из PlatformIO + загрузка `.bin` через веб-страницу; откат на старую прошивку, безопасный режим по кнопке при старте; Wi-Fi включается по запросу | 1.1 | ⬜ |
| 1.3 | **Яркость:** VEML7700 → сглаживание → кривая → ШИМ светодиода у датчика P8 | 0.3 | ⬜ |
| 1.4 | Калибровка: прогон ШИМ 0→100%, отметка порогов P8, гистерезис | 1.3 | ⬜ |
| 1.5 | Точка доступа + веб-страница: кривая яркости, поправка, сброс | 1.3 | ⬜ |
| 1.6 | **Радиоканал пульта:** ESP32 + nRF24L01+ — найти канал (скан по 2400–2525 МГц при нажатии), перехват в promiscuous-режиме, разбор пакетов по кнопкам, повтор → P8 реагирует. Если nRF24 не ловит — донгл nRF52840, крайний случай — SDR | 0.1, 0.5 | ⬜ |
| 1.7 | **BT-клавиатура (бывший 0.2):** принимает ли P8 ESP32 как BLE HID. Если да — перебор Consumer-кодов: что P8 понимает кроме громкости/треков (яркость? день/ночь? Home? навигация?) | 1.1 | ⬜ |
| 1.8 | **Имитация панели Toyota на макетке:** 2 энкодера с кнопкой + несколько кнопок. Слой input: дребезг, долгое нажатие, комбо | — | ⬜ |
| 1.9 | Раскладка управления (см. `architecture.md`) на макетных кнопках, режим обучения яркости (DISP + CONTROL) | 1.3, 1.6, 1.8 | ⬜ |
| 1.10 | Обратная связь без LCD: «виртуальный LCD» в Serial/вебе, мигание светодиода, звуковой сигнал (пищалка). Без этого непонятно, в каком режиме меню панель | 1.9 | ⬜ |
| 1.11 | Временная установка в машину: ESP32 от USB/powerbank, только яркость + пульт с макетной панели. USB-кабель вывести в доступное место (запасной путь прошивки) | 1.2, 1.3, 1.6 | ⬜ |
| 1.12 | **Запасной вариант для ночного режима** (если в 1.7 кода день/ночь не нашлось): проверить обновления прошивки P8 и спросить поддержку ATOTO, есть ли у P8 способ передавать «ночь» в Android Auto (скрытая настройка, вход подсветки и т. п.) | 1.7 | ⬜ |

Результат этапа: прошивка, которая полностью работает с макетной панелью. На этом этапе уже решается реальная проблема с яркостью.
