# ATOTO P8

## Что известно

- Портативный экран с беспроводным Android Auto / CarPlay. Звук в машину — по AUX.
- В комплекте пульт **AC-44F6**: громкость, треки, голосовой ассистент, звонки. В обзорах описан как BT-пульт.
- Универсальный пульт **AC-44F8 несовместим** с P5/P8/P9/P10 → у P-серии свой протокол или привязка.
- Проводного входа для кнопок руля (Key1/Key2), как у стационарных ATOTO, нет (не подтверждено).
- Автояркость по датчику освещённости на **задней** стороне. Работает хорошо, ступеней много (проверено до установки в корпус).
- В корпусе навигации Altezza датчик закрыт; через оптическую трубку реагирует только на фонарик → яркость почти всегда минимальная.
- Ночной режим AA по датчику, похоже, не переключается (наблюдение, не проверено).
